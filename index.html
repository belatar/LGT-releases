Install in Firefox

Signed by Mozilla. Firefox updates it automatically after the first install.

Installing

  1. Click Install in Firefox.
  2. If Firefox says it prevented this site from installing software, click Continue to Installation.
  3. Confirm with Add.

If that doesn't work

Right-click the button, choose Save Link As…, then drag the saved file onto a Firefox window, or use about:addons → gear icon → Install Add-on From File….

How it works

Tracks how your LinkedIn connections do in the daily LinkedIn games, with a dashboard for today that fills and refreshes on its own, and a history per game.

It runs entirely in your browser. It uses your existing linkedin.com login to read the same results the games pages show you. Nothing is sent anywhere else, and it never posts or changes anything on your account. Unofficial, not affiliated with LinkedIn.

Using it

  • Click the toolbar icon to open the dashboard. LGT checks LinkedIn every 15 minutes while Firefox is open (⟳ checks right away).
  • Today: a card per game with your connections' results for today's puzzle: rank, time and ✦ for a flawless solve (no hints, no mistakes). Your row is highlighted. Connections who haven't played yet are listed greyed out at the bottom.
  • History: pick a game to see the standings over all days LGT has seen (played, wins, average rank, best and average time) and every day's top 3 with your own result. History starts on the day you install LGT.
  • LinkedIn may only show a game's connections leaderboard once you've played that game yourself, so if a card stays empty, play it first.
  • Settings (⚙ in the dashboard): check interval, the hidden helper tab, and the public board.
  • Public board: publishes the rankings as an encrypted web page you can open in any browser, for example on your phone. Turn it on under Settings → Public board with a GitHub repository (with GitHub Pages turned on), a fine-grained token for it (Contents: Read and write) and a passphrase. The board page asks for the passphrase and can remember it on that device. Only the encrypted results and the page itself are uploaded, never your LinkedIn login, and the page shows initials instead of profile photos.

Troubleshooting

  • "You're not logged in to LinkedIn": log in at linkedin.com in the same Firefox profile (not in a private window or a different container), then press ⟳.
  • "LinkedIn refused the request": open linkedin.com/games once (it can stay in a background tab), then press ⟳. With the hidden helper tab turned on, LGT does this by itself.
  • "LinkedIn changed the … query": LinkedIn renamed a request. Find the new queryId=… in the browser's Network tab on linkedin.com/games and enter it under Settings → Advanced.
  • Board not published: the message in Settings → Public board says why, usually the token (needs Contents: Read and write on that repository) or an empty repository (add a README).
